# 余烬棋城 · Emberhold v1.1

白昼落子，长夜守城。一款结合昼夜城防经营与自走棋阵容构筑的原创单人 3D 网页游戏。

**[在线游玩](https://starvilfisher-maker.github.io/Emberhold/)** · **[v1.1 发布](https://github.com/starvilfisher-maker/Emberhold/releases/tag/v1.1)** · **[版本记录](CHANGELOG.md)**

## 玩法

- **招募与阵容**：八种棋子、四个阵营、三个职业；三枚同名同星棋子自动合成，最高三星。
- **经营与建设**：刷新商店、升级人口、储蓄利息，建造箭塔、星火中继和农庄。
- **亲自守城**：部队自动战斗，你操纵领主支援前线。携带核心为附近棋子与城防增伤。
- **六夜远征**：逐夜选择祝福，迎击不同方向的敌人，最终击败无光之王。

## 操作

| 操作 | 键位 / 方式 |
| --- | --- |
| 移动领主 | WASD / 方向键 / 触屏摇杆 |
| 冲刺 | 空格 |
| 星火震荡 | Q |
| 携带 / 放下核心 | E |
| 开始守夜 | Enter / 迎接长夜按钮 |
| 暂停 / 取消选择 | Esc |
| 招募棋子 | 点击商店卡牌 |
| 部署棋子 | 点击备战席棋子，再点击地面方格；也可一键上阵 |
| 建造 / 升级 | 点击金色城防基座 |

每夜基础收入 12 金币；每存 10 金币获得 1 利息，上限 5；农庄每级收入 4。羁绊按已部署的不同棋种计算，同名棋子不重复计数。阵亡棋子次日复活，城堡倒下则远征结束。

## 离线游玩

下载 `dist/emberhold-offline.html`，用现代浏览器双击打开即可游玩，无需安装 Node.js 或其他依赖。

存档保存在当前浏览器。在线、离线和本地开发地址各自保存进度；夜晚刷新会回到上一份白昼备战存档。当前版本为单人 PvE。

## 本地开发

需要 Node.js 18 或更新版本，无需安装依赖。

```sh
node server.mjs
```

打开 http://127.0.0.1:5179 。

```sh
node test.mjs          # 游戏规则与六夜完整流程
node build-offline.mjs # 更新离线单文件版本
node build-pages.mjs   # 同步 docs/ 部署文件
```

GitHub Pages 使用 `main` 分支的 `/docs` 目录。修改游戏后运行两个构建命令并提交 `dist` 和 `docs`。v1.1 对应的 Git 标签为 `v1.1`。

## 项目结构

- `dist/engine.js`：经济、阵容、战斗、胜负与存档规则。
- `dist/world.js`：Three.js 场景、低多边形模型、光照与粒子。
- `dist/app.js`：中文界面、键鼠/触屏输入、音效、存档与可选 WebMCP。
- `dist/emberhold-offline.html`：完整离线版本。
- `docs/`：GitHub Pages 静态发布目录。
- `test.mjs`：十项规则检查与六夜通关模拟。
