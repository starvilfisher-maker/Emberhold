# 余烬棋城 · Emberhold v1.5

白昼落子，长夜守城。一款结合昼夜城防经营、自走棋阵容构筑与领主亲自参战的原创单人 3D 网页游戏。

## 开阔战场 · v1.5

- **看清布阵**：新远征从 34 格扩展到 76 格。完整深色格框配合浅色内沿，雪地采用蓝色底纹；金色表示已占用。格线采用三个实例化批次绘制。
- **自由移镜**：地形面积约为原来的 1.96 倍。拖动空地平移，中键 / 右键也可拖图；滚轮或 ± 缩放至 55%–240%。F 归城，点「领主」定位。拖棋子仍然布阵，拖图不会提交移动指令。
- **解决遮挡**：城堡挡住单位或正在布阵时自动淡化，也可点「城堡透视」固定半透明。观景时恢复完整模型。
- **四面来敌**：加宽桥梁，每个入口分三路进军，第 3 夜起有南侧包抄；预告显示实际出兵方向。固守保持在站位附近约一格范围内，突击兵也不会走进出生桥。
- **生命反馈**：敌我、领主、城堡与城防始终显示朝向屏幕的血条，缩放不改变血条像素大小；H 或「血量数值」显示详细生命。低血量有醒目边框。

## 微缩城邦 · v1.4

重绘三种环境的岩岸、石路、桥梁与植被；重建王城、箭塔、晶体中继和风车农庄，细化十二兵种的护甲、武器与饰件。日间光影更有层次，夜晚增加暖窗与城门灯光。模型合批与岸线实例化降低装饰的绘制开销。

点击右上角 **◉ 观景** 或按 **V**，可暂停对局并切换全景、近景、侧景和昼夜光照；**Esc** 返回战场并恢复原镜头。观景只改变显示，不会改变波次、时间、金币与存档。

## 八夜远征

选择翠风河谷、霜月隘口或鎏金遗都，以旅人、守城者或铁誓难度开始。三种战场共享基础棋盘，分别强化城堡恢复、敌军减速或经济收益。

- **十二兵种**：四阵营、三职业，三枚同名同星自动合成，最高三星。羁绊按已部署的不同棋种计算。
- **六件装备**：事件与守夜奖励提供星髓，在军务厅锻造。每枚棋子一件，免费换装；出售和合成不丢装备。
- **三种核心专精**：第 2 日选择烈焰之心、长青圣域或星火网络。本次远征不可更换。
- **六条城防分支**：箭塔、星火中继和农庄达到 2 级后，分别选择两种改造之一。
- **白昼事件**：每个白昼一项事件，金币、星髓、修复与单夜风险收益由你决定；也可跳过。
- **战术布阵**：拖放、换位、撤回；固守与突击；阵型保存与恢复。两块金色高台提供射程 +1.5。
- **特色敌人**：攻城车优先破坏建筑，祭师治疗军团，潜袭者追击后排。第 4 / 8 夜首领提供 2.2 秒红圈预警，Q 可打断。
- **美术动画**：独立兵种模型与矢量肖像，挥击、步行、受击、倒地、碎光、风车、飘雪、旗帜及核心变色。
- **画质与反馈**：1× / 2×，伤害和治疗战报，图鉴，商店概率，三档画质、音量与动效设置。

## 操作

| 操作 | 键位 / 方式 |
| --- | --- |
| 移动领主 | WASD / 方向键 / 触屏摇杆；点地面移动 |
| 冲刺 / 震荡 | 空格 / Q；触屏技能按钮 |
| 携带或放下核心 | E / 核心按钮 |
| 军务厅 | B / 军务按钮 |
| 开始守夜 | Enter / 迎接长夜按钮 |
| 暂停 / 取消 | Esc |
| 招募与锁店 | 点击商店卡牌 / 锁定商店 |
| 部署 | 拖场上或备战席棋子到方格；拖到棋子上交换；拖回备战席撤回 |
| 建造与改造 | 点金色基座，或军务厅 → 城防 |
| 装备 / 姿态 | 军务厅 → 锻造 / 军团 |
| 平移战场 | 拖动空地 / 中键或右键拖动；触屏拖空地 |
| 缩放 / 定位 | 滚轮或 ± / F 归城 / 点「领主」 |
| 生命数值 / 遮挡 | H 或「血量数值」 / 「城堡透视」 |
| 观景 / 返回 | 顶部 ◉ / V；Esc 返回 |

棋子与领主自动攻击附近敌人。遇到远处攻城车或祭师，可以亲自出击，或在下次备战将部分棋子设为突击。

基础收入每夜 12 金币；每存 10 金币获得 1 利息，上限 5；农庄每级收入 4。遗都、祝福与分支可增加收益。阵亡棋子次日复活，领主倒下 8 秒后回归，城堡倒下则远征结束。

## 离线与开发

下载发布页的 `emberhold-offline.html`，用现代浏览器双击打开即可，无需安装依赖。

本地开发需 Node.js 18+，没有 npm 依赖：

```sh
node server.mjs             # http://127.0.0.1:5179，可用 PORT 环境变量改端口
node test.mjs               # 经典规则和六夜通关
node test-interactions.mjs  # 卡牌、拖放、锁店与战报
node test-campaign.mjs      # 装备、事件、分支、首领、存档及三个战场八夜通关
node test-art.mjs          # 场景合批、模型动画、资源回收与镜头恢复
node test-battlefield.mjs    # 扩展地图、进军路线、追击边界、镜头、拖放与血条
node build-offline.mjs      # 构建独立离线文件
node build-pages.mjs        # 同步 docs/ 部署文件
```

GitHub Pages 使用 `main` 分支的 `/docs`。发布工作流检查测试与构建一致性，再生成版本标签、离线文件和源码包；已有发布不会覆盖。

## 结构与素材

- `dist/engine.js`：经济、阵容、战斗、胜负与存档。
- `dist/content.js`：战场、关卡、装备、事件与分支规则。
- `dist/art.js`：主题场景、城堡、城防、棋子细节与静态模型合批。
- `dist/battlefield.js`：布阵格、战场边界、入侵方向与进军路线。
- `dist/battle-visuals.js`：高对比格线、屏幕血条和城堡遮挡。
- `dist/world.js`：Three.js 场景、模型、动画和特效池。
- `dist/portraits.js`：原创矢量兵种肖像。
- `dist/app.js`、`campaign-ui.js`：战场界面、军务厅、输入、音效与存档。
- `dist/interaction.js`、`formation.js`：稳定 UI 更新与直接拖放。
- `docs/`：GitHub Pages 发布文件。
